# java-lotto-precourse

### 기능 구현 목록
- [ ] 로또 구입 금액을 입력받는다.
  - [ ] 구입 금액은 1000원 단위로 입력이 가능하다.
    - [ ] 금액이 1000원 단위로 나누어 떨어지지 않는 경우 오류를 반환한다.
    - [ ] 금액이 숫자가 아닌 문자열인 경우 오류를 반환한다.
    - [ ] 로또는 한번에 최대 50장까지 구매 가능하다.
- [ ] 로또를 발행한다.
  - [ ] 로또 번호의 숫자 범위는 1~45이다.
  - [ ] 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
  - [ ] 발행한 로또 번호 및 수량을 출력한다. 
    - [ ] 수량은 다음과 같이 출력한다. (ex. 8개를 구매했습니다.)
    - [ ] 로또 번호는 다음과 같이 오름차순으로 정렬하여 보여준다. (ex. [8, 21, 23, 41, 42, 43])
- [ ] 당첨 번호를 추첨한다.
  - [ ] 당첨 번호는 중복되지 않는 숫자 6개와 보너스 숫자 1개로 이루어져 있다.
    - [ ] 당첨 번호는 쉼표로 구분하여 입력받는다.
    - [ ] 당첨 번호는 숫자로만 이루어져 있다
    - [ ] 당첨 번호가 될 수 있는 숫자는 1 ~ 45이다.
    - [ ] 마찬가지로 보너스 번호가 될 수 있는 숫자도 1~45이다. 그리고 당첨번호와 중복 될 수 없다.
  - [ ] 당첨 여부를 판단한다.
    - [ ] 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 다음과 같다.
      - 1등: 6개 번호 일치 / 2,000,000,000원
      - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
      - 3등: 5개 번호 일치 / 1,500,000원
      - 4등: 4개 번호 일치 / 50,000원
      - 5등: 3개 번호 일치 / 5,000원
    - [ ] 사용자가 구매한 로또와 당첨 번호를 비교하여 당첨 여부를 확인한다.
    - [ ] 당첨 내역은 다음과 같이 출력 한다. (ex. 3개 일치 (5,000원) - 1개)
    - [ ] 수익률은 소수점 둘째자리에서 반올림한다. 
      - [ ] 수익률은 다음과 같이 계산한다. ((당첨금 / 구매 비용) * 100)
      - [ ] 수익률은 다음과 같이 출력한다. (ex. 총 수익률은 62.5%입니다.)
- [ ] 예외 상황시 에러 문구를 다음과 같이 출력한다.
  - [ ] [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
  - [ ] 에러 문구는 "[ERROR]"로 시작해야 한다.

### 개발 체크 리스트
- [ ] JDK 21 버전에서 실행 가능해야 한다.
- [ ] 자바 코드 컨벤션을 지키면서 프로그래밍한다.
- [ ] indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다.
- [ ] 3항 연산자를 쓰지 않는다.
- [ ] JUnit 5와 AssertJ를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인한다.
- [ ] 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현한다.
- [ ] else와 switch를 쓰지 않는다
- [ ] Java Enum을 적용하여 프로그램을 구현한다.
- [ ] Lotto클래스에 대한 제약 사항이다.
  - [ ] 제공된 Lotto 클래스를 사용하여 구현해야 한다.
  - [ ] Lotto에 numbers 이외의 필드(인스턴스 변수)를 추가할 수 없다.
  - [ ] numbers의 접근 제어자인 private은 변경할 수 없다.
  - [ ] Lotto의 패키지를 변경할 수 있다.
